## 一、背景与目标

同一 SKU 需要向多个 Retailer 同步库存。运营需要统一维护各渠道的分配比例，避免多个渠道独立配置造成超额分配，并支持批量配置、新商品默认值和渠道同步策略。

本期目标：

1. 按 Retailer × SKU 维护比例和排除状态。
2. 可选择限制同一 SKU 跨渠道比例合计不超过 100%。
3. 同时支持单渠道精细配置和多渠道、多 SKU 组合配置。
4. 支持关键词、批量编码及状态筛选，快速定位待处理 SKU。
5. 为各 Retailer 配置实时、每日定时或指定日期同步，并支持手动立即同步。
6. 明确区分局部编辑、页面草稿及最终保存，减少误操作。

## 二、概念与计算口径

### 2.1 名词定义

| 名词 | 定义 |
|---|---|
| Retailer | 库存分配目标渠道，包括 EDI、平台授权、文件传输、自定义类型 |
| 分配账本 | 维护 Retailer × SKU 比例、排除状态及渠道级同步配置的数据集合 |
| 分配比例 | 为该渠道配置的库存池占比，不是已计算出的实际库存数量 |
| 已配置 | 未排除且比例为有效数值，包括 0% |
| 待配置／未配置 | 未排除且比例留空，跳过该渠道该 SKU 的库存同步 |
| 已排除 | 明确不同步该渠道该 SKU，比例不参与合计 |
| 超配 | 同一 SKU 的有效参与分配比例合计大于 100% |
| 页面草稿 | 已在主页面修改或由弹窗／抽屉确认应用、尚未最终保存的配置 |
| 已保存配置 | 最终保存的配置快照；原型仅保留在内存，生产环境应持久化 |

### 2.2 比例规则

- 单项允许 0–100，最多两位小数；无效、负数、超过 100、科学计数法输入不作为有效比例。
- 留空是允许的业务状态，不等同于 0%。
- 0% 为明确零分配，属于已配置项；是否向具体渠道推送库存零值，需渠道适配层明确，不能将其按“未配置”直接跳过。
- 排除保留原比例，恢复后重新按保留比例参与校验；不会自动调整为可用上限。
- 停用 Retailer 保留全部配置，但不参与分配合计及同步。
- 分配比例不要求合计恰好 100%，未分配部分保留，不自动平均分摊或补齐。

### 2.3 计算公式

对 SKU `s`：

```text
有效占用(r, s) = 配置比例
  前提：r 已启用、s 在 r 中未排除、比例有效
  其他情况：0

跨渠道合计(s) = Σ 有效占用(r, s)
其他渠道占用(r, s) = 跨渠道合计(s) − 当前渠道有效占用(r, s)
当前渠道可分配上限(r, s) = max(0, 100 − 其他渠道占用(r, s))
```

- 百分比使用两位小数精度累计，避免浮点误差导致 100% 被误判超配。
- 例：Walmart 40%、Target 30%，其他渠道占用对 Walmart 为 30%，其可分配上限为 70%。
- 上限表示当前渠道最多可以填写多少，不是扣除本渠道当前比例后的全局剩余。
- 校验必须纳入未选中、被搜索隐藏的渠道；不能只累加当前弹窗中的值。

## 四、功能需求

### 4.1 跨 Retailer 分配总量约束

- 页面提供一个全局开关，默认开启。
- 开启：每个 SKU 的跨渠道合计及已启用渠道的新 SKU 默认比例合计均不得超过 100%。
- 关闭：允许跨渠道合计超出 100%，但单项仍必须有效。
- 关闭约束不会自动修改、归一化或清空比例；保留超配状态提示。
- 从关闭切换为开启时，允许先形成待调整的页面草稿，但有超配时不能最终保存。
- 重新启用渠道时重新计算合计，若超配则阻止最终保存，不自动降低其他渠道比例。
- 页面展示新 SKU 默认比例合计；约束开启时展示可继续分配的比例。

### 4.2 Retailer 主列表

| 字段／操作 | 规则 |
|---|---|
| 多选框 | 停用渠道不可选；全选只作用于当前筛选结果中的已启用渠道 |
| Retailer | 名称及连接类型；点击名称打开 SKU 抽屉 |
| 同步状态 | 启用／停用；变更先进入页面草稿，保存后才应对真实任务生效 |
| 总 SKU | 该渠道的 SKU 配置项数量，含排除项 |
| 已配置／待配置 | 分别按本渠道统计；排除项不计入两者 |
| 超配 SKU | 本渠道已启用且为全局超配 SKU 贡献正比例的条目数 |
| 新 SKU 默认比例 | 可留空；有值时须满足单项比例规则 |
| 同步时间 | 显示同步模式及时间摘要，点击打开设置弹窗 |
| 配置 SKU | 打开单渠道右侧抽屉 |

筛选规则：

- Retailer 名称支持忽略大小写的关键词模糊搜索。
- 状态包括全部、已启用、已停用、存在超配。
- 名称搜索与状态筛选取交集。
- 切换搜索或筛选保留渠道选择，已选数量包含隐藏项；实际操作范围在确认弹窗中展示。
- 渠道启停时清除该渠道的选择，避免意外带入后续操作。

### 4.3 新增 Retailer：可搜索下拉直接添加

1. 点击“新增 Retailer”，显示名称搜索框与连接类型。
2. 输入名称后过滤预设选项，忽略大小写。
3. 有匹配选项：点击选项直接添加，不再弹出第二次确认。
4. 无匹配结果且名称非空：提供“新增「输入名称」”，点击即以自定义名称添加。
5. 已添加的选项显示“已添加”并禁用；提交时再次去重，去除首尾空格并忽略大小写。
6. 名称最长 80 字符。
7. 预设选项使用预设连接类型；自定义项使用界面所选类型。
8. 新增渠道默认启用，默认比例留空，当前商品目录中的所有 SKU 为待配置且未排除；同步模式初始为指定日期时间但无预约。
9. 添加仅进入页面草稿，最终仍需保存；不在本页新增实际 EDI／平台连接或授权。

### 4.4 单 Retailer SKU 配置抽屉

#### 布局与入口

- 点击 Retailer 名称或“配置 SKU”从右侧打开宽抽屉，主列表保持稳定。
- 顶部固定显示渠道名、启用状态、关闭按钮。
- 主体包括关键词／批量搜索、状态快捷筛选、选择与批量应用操作、SKU 列表。
- 底部固定显示校验或修改状态，以及“取消”“确认修改”。
- 停用渠道可查看，SKU 输入、排除切换及多选编辑禁用。

#### SKU 字段

| 字段 | 规则 |
|---|---|
| 勾选 | 单选／全选当前搜索和状态筛选后的结果 |
| SKU／商品名称 | 显示编码、名称 |
| 本渠道比例 | 未排除且渠道启用时可编辑 |
| 其他渠道占用 | 根据抽屉草稿和其他渠道页面草稿实时计算 |
| 本渠道可分配上限 | 开启约束时显示上限；关闭时显示“不限制合计” |
| 状态 | 已排除、比例无效、超配、待配置、已配置 |
| 操作 | 排除／恢复；排除不清除已有比例 |

#### 快捷筛选

| 筛选 | 条件 |
|---|---|
| 全部 | 当前搜索范围内全部条目 |
| 未配置 | 比例留空且未排除；不包含 0% 和无效输入 |
| 超配 | 渠道已启用、条目未排除、有效比例大于 0，且该 SKU 跨渠道合计大于 100% |
| 已排除 | 当前渠道该条目已排除 |

- 每个选项显示数量，数量基于当前搜索结果。
- 状态筛选与搜索叠加，不因筛选清除选择；全选仅作用于当前可见结果。
- 无结果展示空态，不自动切换筛选。

#### 单渠道批量应用

1. 勾选多个 SKU，输入一个比例，点击“应用比例”。
2. 同一比例应用于当前渠道的全部所选 SKU，包括被筛选隐藏但仍选中的条目。
3. 覆盖已有比例，取消所选条目的排除状态。
4. 按替换后的完整账本预检；约束开启且任一目标 SKU 超配时，整批不应用并列出问题 SKU。
5. 预检通过只更新抽屉独立草稿，不直接修改主页面；应用后清空本次 SKU 选择及批量比例输入。
6. 单渠道不再打开第二层设置比例弹窗。

#### 草稿、确认与取消

| 动作 | 行为 |
|---|---|
| 打开抽屉 | 从当前页面配置复制独立草稿 |
| 修改比例／排除 | 仅更新抽屉草稿，实时重新计算校验状态 |
| 无效比例 | 行和输入框标红，禁止确认 |
| 约束开启且超配 | 行和输入框标红，底部显示数量，禁止确认 |
| 约束关闭且超配 | 提示超配，可确认；无效比例仍禁止 |
| 没有修改 | “确认修改”禁用 |
| 确认修改 | 再次校验当前渠道所有 SKU 及跨渠道占用，通过后应用到页面草稿并关闭 |
| 取消 | 直接丢弃本次抽屉修改，不改变页面配置 |
| 关闭／Esc | 有修改时确认是否放弃；选择继续编辑则保持抽屉 |

确认抽屉不代表最终保存。若其他渠道仍有独立校验问题，最终页面保存依旧可能被阻止。

### 4.5 SKU 关键词与批量编码搜索

两处提供同一搜索能力：单渠道抽屉、主列表“设置 SKU 比例”弹窗。

- 关键词：编码或名称模糊匹配，忽略大小写，忽略首尾空格。
- 批量搜索：展开输入区粘贴 SKU 编码，支持换行、空格、制表符、英文／中文逗号及分号。
- 批量编码自动去重，忽略大小写，按完整编码精确匹配。
- 查询后展示匹配数量及未找到的编码，不创建商品。
- 普通关键词与批量编码模式互斥：输入普通关键词清除批量条件，批量查询清空普通关键词。
- 查询不自动勾选；用户显式点击“全选搜索结果”后才选中。
- 切换查询保留既有选择；提供清空选择及清除批量筛选入口。
- 清除批量筛选不清除 SKU 选择。

### 4.6 多 Retailer 设置 SKU 比例

#### 入口与布局

- 主列表勾选一个或多个已启用 Retailer 后，点击“设置 SKU 比例”。
- 按钮名称不随渠道数量变化，不使用“批量设置”作为主按钮名称。
- 弹窗左侧为 SKU 搜索及多选列表，右侧为每个已选 Retailer 的独立比例输入。

#### 应用规则

- 每个渠道填写一个有效比例，各渠道比例可不同。
- 每个渠道的输入值统一应用于全部所选 SKU，不是将一个总比例平均分给各渠道。
- 例：选择 Walmart、Target 及 SKU-A001、SKU-B001，分别填写 40%、30%，形成四个配置组合。
- 新值替换对应组合的旧值，不是叠加；覆盖配置时取消对应排除状态。
- 作用范围为所选 Retailer × 全部已选 SKU，包含搜索后隐藏的已选项。
- 未选择 SKU 或任一渠道比例未填／无效时，“应用”禁用。
- 预检需将未选渠道既有占用加入计算，展示目标 SKU 的超配合计。
- 开启约束且任一目标 SKU 超配时，整批拒绝应用，不做部分更新。
- 关闭约束可带超配应用，单项无效仍拦截。
- 应用时再次校验，通过后更新页面草稿、关闭弹窗、清空本次 SKU 选择与比例输入；仍需统一保存。
- 取消、关闭或 Esc 不提交未应用的输入。

### 4.7 新 SKU 默认比例

#### 当前配置需求

- 每个 Retailer 可配置一个默认比例，用于后续新增 SKU，不回写已有配置。
- 已启用渠道的默认比例计入默认合计；停用渠道不计入。
- 约束开启时默认合计不得超过 100%，关闭时可超过但提示风险。
- 默认比例留空允许保存；不自动平均分配，也不把留空解释为 0%。
- 页面不提供“模拟 WMS 新增 SKU”入口。

#### 服务端接入要求（尚未实现）

真实同步任务首次发现新 SKU 时，需要先完成该 SKU 的分配初始化和约束检查，再进行推送；不能由各渠道任务各自随意分配，否则并发时可能超配。

当前默认值方案的边界：有默认值可作为初始化依据；无默认值没有自动分配依据。不得为了让同步成功而偷偷给所有渠道 100% 或自动平分。

**尚待确认的新商品策略：**此前讨论过“统一分配模板／指定渠道承接／待配置并告警”，当前页面尚无策略选择器，也未实现统一模板。上线前须确认：

1. 自动同步是否必须配置有效的初始化模板，否则禁止启用？
2. 部分渠道无默认值时，是否允许其他已配置渠道先同步？
3. 全部默认值为空时，是否明确接受待配置、跳过推送并通知运营？
4. 默认配置失效时，是整 SKU 暂停初始化，还是只暂停受影响渠道？

在该决策确认前，不应将“所有新 SKU 都能自动完成首次同步”作为已满足的验收结论。

### 4.8 每个 Retailer 的同步模式与时间

从主列表“同步时间”列打开设置弹窗，回显已有模式和时间。三种模式互斥，切换保留各模式输入，但只有选中模式生效和参与校验。

| 模式 | 配置及校验 | 列表回显 |
|---|---|---|
| 实时同步 | 不填时间；库存变化时触发 | 实时同步 |
| 每天定时 | 至少一个 HH:mm，可新增／删除多个，不允许重复 | 每天定时及时间点 |
| 指定日期时间 | 多个 YYYY-MM-DD HH:mm，一次性预约，不允许重复；新增时间须晚于当前时间 | 首个时间及总数量 |

- 时间精确到分钟，当前界面按浏览器本地时区解释。
- 指定日期时间允许零条，表示未设置预约，仍可手动同步。
- 已保存但过去的预约不因历史时间而阻止无关配置保存；新增／修改的时间必须为未来时间。
- 确认时按当前模式校验，时间排序后应用到页面草稿；取消不应用未确认内容。
- 再次打开应回显最近已确认的页面配置。
- 最终保存时再次检查新增预约是否已过期。
- 停用渠道不执行任何自动同步，预约和模式配置保留。
- 以上为目标执行语义；当前原型仅配置，没有事件订阅或定时任务。

### 4.9 按所选 Retailer 立即同步

- “立即同步”与“设置 SKU 比例”位于同一选择操作栏，不放在页头。
- 未选择渠道时禁用；只处理已选且已启用的 Retailer，不默认扩大到全部渠道。
- 搜索隐藏但仍选中的渠道也属于范围；确认弹窗列出完整渠道名称及配置数量。
- 存在任何未保存页面更改时，要求先保存，不允许将页面草稿作为同步依据。
- 仅使用启动时已保存的配置快照；SKU 选择不限定立即同步范围，默认处理所选渠道全部可同步 SKU。
- 已配置项包含有效 0%；待配置及排除项跳过，并显示跳过项数。
- 全部无可同步配置时不能确认。
- 执行前重新校验已保存完整账本：有效比例检查、开启约束时的跨渠道合计检查。未选渠道也计入占用。
- 手动同步不修改自动同步模式、每日时间点或指定日期预约。
- 执行中显示状态并阻止重复点击；当前结果为本地模拟完成，不是渠道成功回执。

### 4.10 SKU 总览与反馈原则

- 顶部“SKU 总览”是主动查看工具，展开后按 SKU 展示各已启用渠道分配、合计及剩余／满配／超配状态。
- 总览读取页面草稿；未确认的抽屉草稿不会直接改变主页面总览。
- SKU 行输入时已实时标红，不再重复显示全局 SKU 超配横幅或“查看总览”按钮。
- Retailer 行仍保留超配数量，收起详情后也可定位问题渠道。
- 新 SKU 默认比例无效／超配、时间校验等没有 SKU 行内对应位置的问题，保留必要提示。
- 成功提示简短；无效状态须有文字，不只依赖颜色。

### 4.11 页面统一保存与放弃

```text
已保存配置 → 页面草稿 → 保存全部更改 → 新的已保存配置
                  ↑
             抽屉确认／弹窗应用
```

- 页面级修改包括启停、约束开关、默认比例、新增渠道、已确认同步策略及 SKU 配置。
- 未修改时保存、放弃按钮禁用；有修改时显示未保存状态。
- 保存前检查所有未排除条目的非空比例、默认比例、当前生效时间模式；开启约束时额外校验 SKU 合计和默认合计。
- 存在阻断错误时不可保存；保存函数本身仍须再次检查，不能只依赖按钮禁用。
- “放弃更改”确认后恢复上次已保存快照，并清除相关选择状态。
- 原型的保存快照不落库，刷新后恢复初始样例数据。生产环境必须在服务端保存成功后才显示成功并更新快照。

### 4.12 与库存同步规则的关系

- 导航中“库存同步规则”与“库存分配账本”并列归属策略中心，入口使用 `inventory:write` 权限标识；真实接口仍须独立鉴权。
- 目标架构：账本作为分配比例统一维护与校验来源，同步规则读取已保存账本，不在两处独立维护同一比例。
- 当前规则表单仍使用静态模拟的其他渠道占用数据，并保留可编辑分配比例；尚未读取本页账本，也没有实现账本只读引用及跳转。不能将两个页面描述成已实时联动。
- 规则表单还提供“封顶／跳过／原比例同步并告警”等溢出策略；其中允许强推的策略与本页开启 100% 约束后的硬性限制存在冲突，真实接入时必须明确优先级。建议硬性约束开启时，执行侧不得用强推绕过校验，该建议尚需产品定稿。
- 旧库存同步规则文档包含新 SKU 超额后归一化、待运营配置等不同方案。本版不默认采用自动归一化，新 SKU 最终策略以第 4.7 节的定稿结果为准。

## 五、校验矩阵

| 校验点 | 无效单项比例 | 约束开启且超配 | 约束关闭且超配 | 校验范围 |
|---|---|---|---|---|
| 抽屉单项输入 | 标红 | 标红 | 状态提示 | 当前抽屉 + 其他渠道页面草稿 |
| 抽屉批量应用 | 禁止应用 | 整批拒绝 | 允许 | 目标 SKU + 全部渠道 |
| 抽屉确认修改 | 禁止确认 | 禁止确认 | 允许 | 当前渠道全部 SKU + 全部渠道占用 |
| 多渠道弹窗应用 | 禁止应用 | 整批拒绝 | 允许 | 所选组合替换后的完整占用 |
| 保存全部更改 | 禁止保存 | 禁止保存 | 允许 | 完整账本、默认比例及生效时间配置 |
| 立即同步 | 禁止执行 | 禁止执行 | 允许 | 已保存完整账本；只推送所选渠道 |

空值不是无效输入：单项编辑可留空；但批量“应用比例”要求明确输入数值。

## 六、数据与后端接入要求

### 6.1 逻辑数据结构

| 对象 | 关键字段 |
|---|---|
| 账本配置 | 全局约束开关、配置版本 |
| Retailer | 稳定 ID、名称、连接类型、启用状态、默认比例 |
| SKU 分配 | Retailer ID、SKU 编码、比例（可空）、排除标识 |
| 同步策略 | Retailer ID、模式、每日时间点、指定日期时间列表 |
| 执行记录（待接入） | 任务 ID、触发来源、配置版本、目标渠道、执行状态、处理／跳过／失败数量、原因 |

生产字段使用明确数值／空值及时间类型，不直接照搬页面字符串。SKU 主数据来自 WMS 或商品服务，本页不创建 SKU。

### 6.2 必须补齐的服务端保障

以下为接入要求，不代表现有原型已提供：

1. 服务端以同一口径校验分配约束，禁止仅依靠前端。
2. 保存配置采用原子提交和版本冲突检查，避免多人分别保存后合计超配。
3. 新 SKU 初始化采用幂等及并发保护，跨渠道初始化不能重复占用。
4. 手动、实时、定时任务读取已保存版本，不读取未提交草稿。
5. 后端持久化同步时区，不能依赖执行服务器的默认时区；夏令时和跨时区规则需确认。
6. 对同一渠道／SKU 的重复触发提供幂等或去重，避免手动与自动任务重复推送。
7. 同步失败区分校验失败、渠道未授权、映射缺失、接口失败等，不以“任务提交成功”替代“渠道同步成功”。
8. 推送数量计算口径（可用库存基数、仓库范围、取整、安全库存、固定数量覆盖）与库存同步规则统一定义，不在本页自行发明另一套公式。

## 七、验收场景

| 编号 | 场景 | 预期 |
|---|---|---|
| AC-01 | 约束开启，两个渠道为 60%、50% | 超配行标红；相关确认／保存按校验点阻断 |
| AC-02 | 比例为 33.33%、33.33%、33.34% | 合计 100%，不误报超配 |
| AC-03 | 关闭约束后保留 110% 合计 | 超配提示保留，允许确认保存，无自动归一化 |
| AC-04 | 停用一个占 40% 的渠道后再启用 | 停用时释放参与占用，重启后重算；超配时阻止保存 |
| AC-05 | 比较留空、0%、排除 | 留空计待配置，0% 计已配置，排除不计占用 |
| AC-06 | 抽屉修改后取消 | 主页面配置不变化 |
| AC-07 | 抽屉修改后关闭／Esc | 提示是否放弃，可返回继续编辑 |
| AC-08 | 抽屉确认后未最终保存 | 页面显示未保存，立即同步不可确认 |
| AC-09 | 抽屉勾选多个 SKU 批量应用，其中一个超配 | 整批拒绝，不部分更新 |
| AC-10 | 两个渠道、两个 SKU 分别设置 40%、30% | 准确更新四个组合，其他组合不受影响 |
| AC-11 | 弹窗只选两个渠道，第三渠道已有 50% | 校验包含第三渠道，不因未选择而漏算 |
| AC-12 | 批量粘贴重复编码及不同大小写 | 去重精确匹配，查询不自动勾选 |
| AC-13 | 批量搜索有未命中编码 | 展示匹配数量及未找到编码，不创建 SKU |
| AC-14 | 搜索与未配置／超配／排除筛选组合 | 取交集，数量随搜索及比例变更更新 |
| AC-15 | 勾选后切换搜索并全选当前结果 | 旧选择保留，全选只新增当前结果；应用含全部已选项 |
| AC-16 | 新增预设 Retailer 或搜索无结果后创建 | 点击直接添加，重复名称禁止；新增配置待保存 |
| AC-17 | 同步模式切换后重新打开 | 回显已确认模式及时间，未生效模式不触发任务 |
| AC-18 | 每日时间为空／重复；新增预约为过去时间 | 阻止确认并显示可理解的错误 |
| AC-19 | 指定日期没有预约 | 允许保存，无预约执行，仍可手动同步 |
| AC-20 | 只选 Walmart 立即同步 | 确认范围与执行范围仅 Walmart，不包括其他渠道 |
| AC-21 | 有未保存更改或无已配置 SKU 立即同步 | 不能执行，提示相应原因 |
| AC-22 | 主页面放弃更改 | 恢复上次保存快照并清除选择 |
| AC-23 | 默认比例合计超过 100% | 开约束禁止保存，关约束仅提示；单项无效始终阻止 |

服务端接入后还须补充：多人保存冲突、新 SKU 并发初始化、调度幂等、事件重放、渠道失败重试及跨时区测试。

## 八、未决事项与上线前门槛

| 事项 | 当前结论／需要决策 |
|---|---|
| 分配池范围 | 原型仅按 SKU 累加；生产是否按租户、货主、仓库／库存池划分，需明确唯一约束维度 |
| 无默认比例的新 SKU | 自动同步如何兜底未确认；不得宣称自动初始化已完成 |
| 统一分配模板 | 讨论过但尚未实现，不属于当前页面能力 |
| 同步时间与规则执行频率 | 需明确唯一调度来源，避免账本与同步规则重复触发 |
| 0% 的渠道输出 | 账本保留零分配语义；具体是否发送零库存、如何处理渠道下架，需适配说明 |
| 新建自定义 Retailer | 当前只新增账本条目；真实渠道连接、授权、标识映射待接入 |
| 实际任务结果 | 任务查询、失败详情、重试、审计日志及权限控制待设计／接入 |
| 配置持久化 | 原型内存快照不是生产保存；上线须完成持久化与服务端校验 |
